# SportyShoes QA Testing Framework

## Project Description

This project implements a complete QA testing framework for the SportsShoes e-commerce application.

The project includes:

- REST API creation
- Selenium automation testing
- JUnit unit testing
- JMeter performance testing
- Postman API testing

---

## Technologies Used

- Java
- Maven
- Eclipse
- Selenium WebDriver
- JUnit 5
- JMeter
- Postman
- Git
- GitHub

---

## Project Tasks

### Task 1
Develop REST APIs for:
- Retrieve all products
- Retrieve all users

### Task 2
Automate UI testing using Selenium Page Object Model.

### Task 3
Unit testing of backend classes using JUnit.

### Task 4
Performance testing using Apache JMeter.

### Task 5
API testing using Postman.

---

## How to Run

1. Clone the repository.
2. Import as a Maven project.
3. Configure the database.
4. Run the application.
5. Execute Selenium tests.
6. Run JUnit tests.
7. Execute JMeter scripts.
8. Import the Postman collection and run the API tests.

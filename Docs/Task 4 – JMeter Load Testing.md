# Task 4 – JMeter Load Testing

## Objective

Perform load testing on the SportsShoes application using Apache JMeter.

---

## Technologies Used

- Apache JMeter

---

## Pages Tested

- Homepage
- Product Details Page

---

## Steps Performed

1. Created Thread Group.
2. Configured virtual users.
3. Added HTTP Request Samplers.
4. Added View Results Tree.
5. Added Summary Report.
6. Added Graph Results.
7. Executed load test.
8. Analysed performance.

---

## Algorithm

### Homepage Load Test

Step 1: Open JMeter.
Step 2: Create Thread Group.
Step 3: Configure 50 virtual users.
Step 4: Add Homepage HTTP Request.
Step 5: Execute test.
Step 6: Record response time.
Step 7: Analyse throughput.

---

### Product Page Load Test

Step 1: Create HTTP Request.
Step 2: Access Product Detail page.
Step 3: Execute with multiple users.
Step 4: Measure response time.
Step 5: Analyse results.

---

## Expected Result

- Homepage loads successfully.
- Product page handles concurrent users.
- Response time remains acceptable.

---

## Outcome

Successfully completed load testing and verified application performance.

# Task 5 – Postman

## Objective

Test the REST APIs developed for the SportsShoes application using Postman.

---

## Technologies Used

- Postman

---

## APIs Tested

GET /api/products
GET /api/users

---

## Steps Performed

1. Created Postman Collection.
2. Added GET requests.
3. Executed API requests.
4. Verified response status.
5. Verified response time.
6. Saved collection.

---

## Algorithm

### Products API

Step 1: Open Postman.
Step 2: Create GET request.
Step 3: Enter Products API URL.
Step 4: Click Send.
Step 5: Verify HTTP Status 200.
Step 6: Verify response time.

---

### Users API

Step 1: Open Postman.
Step 2: Create GET request.
Step 3: Enter Users API URL.
Step 4: Click Send.
Step 5: Verify HTTP Status 200.

---

## Expected Result

- Products API returns all products.
- Users API returns all registered users.
- All API tests pass successfully.

## Outcome

Successfully validated all REST API endpoints using Postman.

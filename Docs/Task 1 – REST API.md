# Task 1 – REST API Development

## Objective

Develop REST API endpoints for the SportsShoes application to retrieve:

- All available products
- All registered users

---

## Technologies Used

- Java
- Maven

---

## Steps Performed

1. Created Product API Servlet.
2. Created User API Servlet.

---

## Algorithm

### Retrieve Products

Step 1: Receive GET request.
Step 2: Connect to the database.
Step 3: Retrieve all products.

---

### Retrieve Users

Step 1: Receive GET request.
Step 2: Connect to the database.
Step 3: Retrieve all registered users.

---

## Expected Result

- Products endpoint returns all products.
- Users endpoint returns all registered users.
- APIs return HTTP Status 200.

---

## Outcome

Successfully developed and tested REST API endpoints for the SportsShoes application.
